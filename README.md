# SASA RUN

نسخة أولية قابلة للعب من لعبة SASA RUN باستخدام React + Three.js + React Three Fiber.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. فك ضغط المشروع.
3. افتح مجلد المشروع في الطرفية ونفّذ:
   ```bash
   npm install
   npm run dev
   ```
4. افتح الرابط المحلي الذي يعرضه Vite على الهاتف أو الكمبيوتر.

## التحكم
- اسحب يميناً/يساراً لتغيير المسار.
- اسحب لأعلى للقفز.
- اسحب لأسفل للانزلاق.
- زر Ⅱ لإيقاف اللعبة.

## الموجود حالياً
- مشهد ثلاثي الأبعاد بثلاثة مسارات، شخصية، عملات، حواجز وقطارات كعقبات.
- توليد مستمر للعناصر وزيادة تدريجية للسرعة.
- تصادم، نقاط، أفضل نتيجة وعملات محفوظة محلياً.
- شاشة رئيسية، إيقاف/استكمال، متجر شخصيات مبسط، واختيار أربعة عوالم لونية.
- واجهة عربية مناسبة لشاشة الهاتف.
